Files and calculation

Required: .bin or .ggrid (same basename as the SIZ or STR) for the FullProf surface, .siz for size or .str for strain and .pcr for phase, symmetry and size model. Optional: .out and .mic for consistency checks.

Read FullProf size grid → extract its half-level surface → show dimensionless grid axes. Read SIZ/MIC independently for physical size metrics. Strain is not a length; STR values are reported separately in their original file convention.

3
Use a compatible size model
! … GauSiz LorSiz Size-Model
  …   …      …    your model

Keep the model, coefficients and constraints appropriate to your symmetry.

These are excerpts, not replacement PCR lines. Keep the other fields. Run FullProf again and load the resulting *_size_#.siz.

Instrumental profile and model notes

For the constant-wavelength TCH workflow for compatible refinements, Npr = 7 and an instrumental resolution file (Res) are used. The IRF is used by FullProf; it is not recalculated here. Other profiles and TOF workflows must follow their own FullProf settings.

Jvi = 5 requests the directional output; it cannot turn a reflection-selective broadening model into a continuous size field. A valid finite .siz remains mandatory.

Interpretation of the SIZ representation

This is a representation of the directional apparent sizes obtained from the refinement, plotted as r = Dₕ/2. It does not establish the physical shape of a crystallite or guarantee that the plotted outer dimensions match those of a real particle.

FullProf defines the size derived from the integral breadth as follows: gives the volume-averaged apparent size of the crystallites in the direction normal to the scattering planes. FullProf microstructure documentation, Eq. (14).

The first paragraph explains the interpretation of this app’s radial construction; it is not a verbatim quotation from FullProf.

Directional metrics and interpretation

Metrics become available after a valid plot is generated.

The plot uses the FullProf grid surface. Grid axes are dimensionless and centered on its bounding box. SIZ radial spans and cylindrical estimates are separate results; neither is automatically the physical particle size. Colors indicate radius in grid coordinates, not Dₕ. No ratio uncertainty is inferred without covariances.

Size-model reference

All size-model families described in the reference manual are recognized. A finite, complete directional .siz is required for plotting. Reflection-selective models are identified and explained, but do not produce an inferred closed surface.
